# Goedgedrag Wanica Centrum App

Online aanvraagapplicatie voor Verklaring Omtrent het Gedrag voor Districtscommissariaat Wanica Centrum.

## Structuur
- `app.py`: Hoofdscript voor de Streamlit applicatie
- `requirements.txt`: Python afhankelijkheden voor Streamlit Cloud
- `.streamlit/config.toml`: Thema-instellingen (Groen/Wit)
- `uploads/`: Map voor geüploade bestanden
